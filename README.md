# SMART TRAFFIC LAB — Ақылды қаланың математикалық зертханасы

Оқу симуляторы: «Ақылды қала жағдайында жол қозғалысын тиімді басқарудың математикалық модельдері» (Қадырбек Жанель, 7 «А»; жетекші — Ашимханова Ф. Т.).
Учебный симулятор дорожного движения: фиксированное vs адаптивное управление светофором, воспроизводимые эксперименты, статистика, PDF/CSV.

## Іске қосу / Запуск
```bash
npm install
npm run dev      # http://localhost:5173
npm test         # unit-тесттер (vitest), 32 тест
npm run build    # dist/
```
Node.js 18+ (тексерілді: 22).

## Vercel-ге жариялау / Публикация
1. Архивті ашып, түбірін GitHub репозиторийіне жүктеңіз (`node_modules`, `dist` қажет емес).
2. Vercel → Add New → Project → Import Git Repository.
3. Framework: **Vite**; Build: `npm run build`; Output: `dist` (бәрі `vercel.json`-да бар). Deploy.
4. Міндетті емес: AI зерттеушіге LLM қосу үшін Vercel → Settings → Environment Variables → `ANTHROPIC_API_KEY` (кілт тек серверде, `api/assistant.js`). Онсыз барлық түсіндірме жергілікті ережелерден құрылады.

## Версия 2: простой интерфейс для ученика
- 5 разделов: **Басты бет · Ақылды қала · Тәжірибе жасау · Нәтижелер · Жоба туралы** + кнопка **«Қорғау режимі»**.
- Эксперимент запускается за 2 нажатия: «Зерттеуді бастау» → «Бастау». Готовые настройки: Көлік саны (Аз/Орташа/Көп), Бағдаршам түрі (Қарапайым/Ақылды), Қозғалыс жылдамдығы (только скорость анимации).
- Все числовые параметры — в свёрнутом блоке «Қосымша баптаулар».
- Лаборатории: «Қай бағдаршам тиімді?» (3 шага), «Қай жол тиімді?» (точки выбираются на карте, Дейкстра пошагово), «Көлік қозғалысын есептейік» (q = ρ·v пошагово, KaTeX).
- 10 экспериментов — мастер из 5 шагов (Мақсат → Болжам → Тәжірибе → Нәтиже → Қорытынды); выводы и проверка прогноза строятся только из вычислений.
- Режим защиты `/defense`: 6 этапов, кнопки Артқа/Келесі, стрелки клавиатуры, полноэкранный режим, перезапуск; без автоперехода.
- Визуализация — Canvas 2D с интерполяцией между шагами ядра (без «телепортации»).

**Стек.** Оставлен Vite + React + TypeScript вместо Next.js: сайт полностью клиентский, на Vercel работает так же, а рабочее ядро и тесты сохранены без переписывания. Стили — собственные CSS-токены вместо Tailwind (тот же результат, меньше зависимостей). Recharts, KaTeX, Canvas 2D — как в ТЗ.

## Құрылымы / Структура
```
src/core/        расчётное ядро без UI (тестируется в Node)
  engine.ts      пошаговая микросимуляция (Δt 0.2–1 с), очереди, метрики, инварианты
  signals.ts     фиксированный цикл и адаптивный S_i = N_i + α·W_i (minGreen/maxGreen/maxRed)
  network.ts     условная сеть: 1 перекрёсток или коридор из 3, полосы, фазы, траектории
  demand.ts      генерация прибытий (Пуассон / регулярно, пик, асимметрия, грузовики) по seed
  graph.ts       Дейкстра с журналом шагов, альтернативные пути
  flow.ts        q = ρ·v, Гриншилдс, Пуассон
  stats.ts       t-тест, Уилкоксон, Шапиро–Уилк, χ², Фишер, Уэлч, Манн–Уитни
  experiments.ts E01–E10, запуск, агрегаты
src/lib/         store (localStorage), PDF (jsPDF + DejaVu), CSV, Web Worker, правила AI
src/pages/       / /city /lab /lab/signals /lab/routes /lab/math /lab/E01…E10 /results /about /defense (старые адреса перенаправляются)
src/components/SimCanvas.tsx  Canvas-рендер сети, машин и светофоров
src/lib/useSimulation.ts      анимация ядра с интерполяцией
api/assistant.js опциональный серверный endpoint LLM (ключ только на сервере, лимит запросов)
public/sw.js     офлайн-кэш (PWA)
materials/       ТЗ и исходные данные (seed_graph.json, scenario_example.json, experiment_plan.csv)
public/materials исходный PDF/DOCX для скачивания с сайта
tests/           unit-тесты ядра
```

## Критерийлерді тексеру / Проверка критериев приёмки
| № | Критерий | Как проверено |
|---|---|---|
| 1 | Одинаковый seed → одинаковый результат | тест «бірдей seed»; кнопка «Тексеру» по ID сценария |
| 2 | Нет одновременного зелёного у конфликтующих направлений | инвариант в ядре + тест (в т.ч. перегрузка, коридор, грузовики) |
| 3 | Режим меняет алгоритм и результаты | тест «режим алгоритмді өзгертеді» |
| 4 | Интенсивность меняет прибытия и метрики | тест «қарқындылық» |
| 5 | Дейкстра на графе A–D | тест сверяет со всеми простыми путями |
| 6 | q = ρv | unit-тесты |
| 7 | Идентичный спрос при сравнении | один список событий передаётся обоим ядрам |
| 8 | Нет зашитых 61,7 / 35 с в KPI | тест сканирует `src/` |
| 9 | PDF с казахскими буквами | встроенный шрифт DejaVu Sans (подмножество) |
| 10 | CSV для Excel | UTF-8 BOM, «;» и десятичная запятая (или стандарт «,») |
| 12 | Нет ошибок консоли | проверено Playwright (Chromium) на всех маршрутах |
| 13 | `npm install && npm run build` | проверено |

Не проверено вручную: реальные устройства Android Chrome и Edge (вёрстка проверена в Chromium на 375 px и 1440 px).
